# Garofalo Desk

Brand di ClantoDesk per Fattorie Garofalo S.p.A. (livello 1, Windows e macOS).

Questo repo contiene solo `brand.json` e `icons/`. La build la fa il workflow
«Partner build» di `clanto/clantodesk-client` con `partner: fattoriegarofalo`,
che firma con i certificati Clanto e pubblica qui la release
(`fattoriegarofalo-<versione>-x86_64.exe`, `.msi`, `.dmg`).

Le icone sono ricavate dalla bufala del logo di fattoriegarofalo.it.
Regole dei campi e delle icone: `res/partner-template/README.md` in
`clanto/clantodesk-client`.
